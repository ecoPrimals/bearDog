NestGate Integration Adapter - MIGRATED TO UNIVERSAL PATTERN

TECHNICAL DEBT ELIMINATION COMPLETE ✅

This adapter has been migrated from hardcoded NestGate-specific logic to the universal adapter pattern. BearDog now treats NestGate like any other primal in the ecosystem, using capability-based routing instead of specialized adapters.

§Migration Benefits

  • ✅ No hardcoded primal names - Uses generic capability requests
  • ✅ Ecosystem sovereignty - Works with any storage provider
  • ✅ Unified error handling - Uses canonical BearDogError
  • ✅ Universal adapter pattern - Consistent with SongBird, ToadStool, etc.
