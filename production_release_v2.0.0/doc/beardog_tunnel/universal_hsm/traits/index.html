§Universal HSM Traits - Canonical Definitions

SINGLE SOURCE OF TRUTH FOR HSM TRAITS

This module defines the canonical HSM provider traits that replace all fragmented trait definitions throughout the codebase. All HSM providers must implement these unified traits.
