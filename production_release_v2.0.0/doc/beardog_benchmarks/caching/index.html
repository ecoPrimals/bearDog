Caching configuration management

This module provides configuration for various caching systems including Redis, Memcached, and custom caching implementations.

Split into focused sub-modules for maintainability:

  • distributed - Main distributed caching configuration
  • redis - Redis cluster configuration
  • optimization - SIMD and performance optimization
  • strategies - Cache strategies and algorithms
  • utils - Utility functions
