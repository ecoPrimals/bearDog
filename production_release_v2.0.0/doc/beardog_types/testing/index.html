§Unified Testing Configuration Module

ELIMINATES TEST CONFIGURATION FRAGMENTATION

This module provides canonical testing configuration types that replace the fragmented test configuration definitions found across:

  • tests/common/harness.rs (TestHarnessConfig)
  • tests/common/metrics.rs (MetricsConfig)
  • tests/integration_comprehensive.rs (IntegrationTestConfig)
  • Various other test files with duplicate config structs

§Design Principles

  1. Single source of truth - All test configs defined here
  2. Environment-driven - Support for different test environments
  3. Modular organization - Separate configs for different test types
  4. Backward compatibility - Smooth migration from existing configs
