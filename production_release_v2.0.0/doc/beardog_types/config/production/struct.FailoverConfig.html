COMPREHENSIVE CANONICAL FAILOVER CONFIGURATION

ELIMINATES 6 DUPLICATE FAILOVER CONFIGURATIONS

This unified FailoverConfig consolidates features from:

  • beardog-types/src/config/network.rs::FailoverConfig (network failover with recovery)
  • beardog-config/src/caching.rs::FailoverConfig (Redis failover with retries)
  • beardog-tunnel/src/tunnel/hsm/manager/config.rs::FailoverConfig (HSM manager failover)
  • beardog-tunnel/src/tunnel/hsm/config.rs::FailoverConfig (HSM config failover)
  • beardog-config/src/load_testing/mod.rs::FailoverConfig (load testing failover)
  • Plus the original production failover configuration

§Comprehensive Feature Set

  • Endpoint Management: Primary/secondary/tertiary endpoint configuration
  • Health Monitoring: Intervals, timeouts, failure thresholds
  • Circuit Breaker: Protection with thresholds and reset timeouts
  • Retry Logic: Configurable retry attempts with delays
  • Recovery Strategies: Multiple recovery approaches (immediate, gradual, manual)
  • Load Balancing: Multiple strategies during failover scenarios
  • Auto-failback: Automatic recovery with configurable delays
  • Generic Thresholds: Support for both count-based and percentage-based thresholds
