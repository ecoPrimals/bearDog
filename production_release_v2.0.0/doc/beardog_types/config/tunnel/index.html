§Canonical Tunnel Configuration Types

ELIMINATES TUNNEL CONFIG FRAGMENTATION

This module consolidates tunnel configurations from:

  • beardog-tunnel/src/tunnel/hsm/types/config.rs (TunnelFailoverConfig, etc.)
  • beardog-tunnel/src/tunnel/config.rs (BStpConfig, GamingConfig, etc.)
  • Multiple discovery and orchestration configurations across tunnel modules

§Unified Tunnel Architecture

  1. Consolidated Discovery System - Single comprehensive HSM discovery configuration
  2. Unified Failover Management - Common failover patterns across all tunnel systems
  3. Standardized Load Balancing - Consistent load balancing across HSM providers
  4. Gaming Optimization Config - Specialized gaming performance configurations
