§Canonical Node Registry Configuration Types

ELIMINATES NODE REGISTRY CONFIG FRAGMENTATION

This module consolidates node registry configurations from:

  • beardog-node-registry/src/node_registry/types/config/p2p.rs (P2PConfig)
  • beardog-node-registry/src/node_registry/types/config/federation.rs (FederationConfig)
  • beardog-node-registry/src/node_registry/types/config/registry.rs (RegistryConfig)
  • beardog-node-registry/src/node_registry/types/config/phonebook.rs (PhonebookConfig)
  • beardog-node-registry/src/node_registry/types/config/bootstrap.rs (BootstrapConfig)

§Unified Node Registry Architecture

  1. Consolidated P2P Networking - Single comprehensive peer-to-peer configuration
  2. Unified Federation Management - Common federation patterns across registries
  3. Standardized Discovery - Consistent node discovery and registration
  4. Enterprise Clustering - Multi-registry federation configuration
