§Canonical Discovery Configuration System

ELIMINATES 9+ DISCOVERY CONFIG DUPLICATES

This module consolidates all discovery configuration types from across the BearDog ecosystem into a single, comprehensive canonical system that supports:

  • Service Discovery (Universal ecosystem integration)
  • HSM Discovery (Hardware Security Module detection)
  • Node Discovery (P2P network node finding)
  • Ecosystem Discovery (Multi-ecosystem service location)
  • Tunnel Discovery (Secure tunnel establishment)
  • Adapter Discovery (Dynamic adapter loading)
