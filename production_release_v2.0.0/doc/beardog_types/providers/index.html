§Unified Provider Trait System

ELIMINATES PROVIDER TRAIT FRAGMENTATION

This module provides the canonical provider traits that replace the fragmented provider trait definitions found across:

  • beardog-adapters/src/adapters/universal/traits.rs (PrimalProvider)
  • beardog-core/src/universal_primal_provider.rs (UniversalPrimalProvider)
  • beardog-tunnel/src/universal_hsm/traits.rs (UniversalHsmProvider)
  • beardog-security/src/types/mod.rs (SecurityProvider)
  • beardog-tunnel/src/tunnel/hsm/software_hsm/types.rs (CryptoProvider)
  • beardog-tunnel/src/tunnel/hsm/safe_ffi/traits.rs (SafeHardwareProvider) ✅ ELIMINATED
  • beardog-api/src/api/cache.rs (CacheProvider)
  • beardog-tunnel/src/tunnel/security_provider.rs (BStpSecurityProvider) ✅ REMOVED

§Design Principles

  1. Single trait hierarchy - Clean inheritance from BaseProvider
  2. Domain-specific extensions - Security, HSM, Crypto specializations
  3. Backward compatibility - Smooth migration path from existing traits
  4. Compile-time safety - Strong typing with generic constraints
