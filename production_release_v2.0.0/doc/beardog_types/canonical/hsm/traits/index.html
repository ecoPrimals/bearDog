§Modern Vendor-Agnostic HSM Traits

ZERO VENDOR LOCK-IN - Universal HSM abstraction layer

This module provides a modern, capability-based HSM architecture that works with ANY vendor:

  • Android StrongBox, iOS Secure Enclave, TPM, PKCS#11, Cloud HSMs
  • Runtime capability discovery and adaptation
  • Zero-cost abstractions with compile-time optimization
  • Pluggable vendor adapters without code changes
