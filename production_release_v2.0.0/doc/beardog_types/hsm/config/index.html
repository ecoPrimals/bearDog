§HSM Configuration Types

CONSOLIDATES FRAGMENTED CONFIG DEFINITIONS

This module eliminates the fragmented HSM configuration definitions found in:

  • beardog-tunnel/src/universal_hsm/traits.rs (HsmConfig - unified)
  • beardog-tunnel/src/tunnel/hsm/types/config.rs (HsmConfig - complex)
  • Various other config fragments across tunnel modules
