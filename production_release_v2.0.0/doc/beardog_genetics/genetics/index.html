BearDog Genetics Engine

Implements genetic algorithms for BearDog node reproduction and evolution.

This module was refactored from a large file to improve maintainability. The genetics engine enables BearDog nodes to spawn offspring by combining their cryptographic “genetics” - capabilities, security traits, and cryptographic material.
