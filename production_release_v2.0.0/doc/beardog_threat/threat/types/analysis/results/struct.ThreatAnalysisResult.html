Expand description

Threat analysis result structure

Contains the results of analyzing a security event for potential threats and anomalies.

Fields§

§analysis_id: String

Unique analysis identifier

§event_id: String

Event ID that was analyzed

§timestamp: DateTime<Utc>

Analysis timestamp

§threats_detected: usize

Number of threats detected

§confidence_score: f64

Analysis confidence score (0.0 to 1.0)

§analysis_time_ms: u64

Time taken for analysis in milliseconds

§threat_events: Vec<ThreatEvent>

Detected threat events

§ml_predictions: Vec<MlPrediction>

ML predictions (if available)

§metadata: HashMap<String, String>

Additional analysis metadata
