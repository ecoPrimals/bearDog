1//! Threat intelligence types
2//!
3//! This module contains types for threat intelligence feeds, indicators,
4//! and threat intelligence data structures.
5//!
6//! ## Features
7//! - Threat intelligence feed management
8//! - Indicator of compromise (IOC) types
9//! - Feed status and update tracking
10//! - Intelligence data correlation
11//! - Threat actor attribution
12//!
13//! ## Example
14//! ```rust
15//! use beardog::threat::types::{ThreatIntelligenceFeed, ThreatIndicator, IndicatorType};
16//! use chrono::Utc;
17//!
18//! let indicator = ThreatIndicator {
19//!     indicator_type: IndicatorType::IpAddress,
20//!     value: "192.168.1.100".to_string(),
21//!     confidence: 0.9,
22//!     confidence_score: 0.9,
23//!     first_seen: Utc::now(),
24//!     last_seen: Utc::now(),
25//!     description: "Known malicious IP".to_string(),
26//!     ..Default::default()
27//! };
28//! ```
29//!
30//! This module is organized into focused sub-modules:
31//! - `enums` - Enumeration types for feed types, statuses, and frequencies
32//! - `indicators` - Threat indicator types and functionality
33//! - `feeds` - Threat intelligence feed management
34

36pub mod feeds;
37pub mod indicators;
