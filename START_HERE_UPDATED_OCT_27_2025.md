## 🚀 **QUICK START COMMANDS**

### Get Running:
```bash
# Clone and build
git clone <repo>
cd beardog
cargo build

# Run tests
cargo test

# Check coverage
cargo tarpaulin --out Html

# Format code
cargo fmt --all

# Lint code
cargo clippy --all-targets

# View docs
cargo doc --no-deps --open
```

### Development:
```bash
# Run specific crate tests
cargo test -p beardog-core
cargo test -p beardog-security

# Run with logging
RUST_LOG=debug cargo test

# Check file sizes (should all be <1000 lines)
find crates -name "*.rs" -exec wc -l {} + | awk '$1 > 1000'

# Count unwraps
grep -r "\.unwrap()\|\.expect(" crates/ --include="*.rs" | wc -l
```
