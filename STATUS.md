## 🚀 Deployment

### Production Deployment

```bash
# Build production binary
cargo build --release --workspace

# Run production server
./target/release/beardog-api

# Or use Docker
docker build -t beardog:latest -f docker/Dockerfile.production .
docker run -p 8080:8080 beardog:latest
```

### Configuration

BearDog works with **zero configuration** but supports customization:

```bash
# Environment variables
export BEARDOG_API_PORT=8080
export BEARDOG_DISCOVERY_PORT=9090

# Or config file
cp configs/beardog-config-template.toml beardog.toml
```

See `docs/PRODUCTION_DEPLOYMENT_GUIDE.md` for details.
