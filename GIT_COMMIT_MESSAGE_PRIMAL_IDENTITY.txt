## Summary
Eliminates environment variable coupling in production code by implementing
explicit dependency injection pattern using Arc<PrimalIdentity>. This enables
fully concurrent testing and fail-fast configuration validation.

### Core Implementation

  - for_test() - Explicit test configuration (concurrent-safe)
  - encryption_tag() - Helper method

### Test Updates (Concurrent-Safe)

- No environment variable manipulation in handler tests

## Impact

### Before (Anti-Pattern)
- Hidden dependencies (env vars read in handlers)
- Global mutable state (std::env::var)
- Silent "unknown" fallbacks (masked errors)
- Tests must be serialized (#[serial_test])
- Race conditions in concurrent tests

### After (Modern Rust)
- Explicit dependencies (visible in constructors)
- Immutable shared state (Arc<PrimalIdentity>)
- Fail-fast validation (errors at startup)
- Tests run concurrently (no #[serial_test] needed)
- Zero race conditions
