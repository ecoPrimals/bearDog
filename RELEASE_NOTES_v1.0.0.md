## 🚀 **GETTING STARTED**

### **Quick Start**
```bash
# Install Rust (1.70+)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Clone BearDog
git clone https://github.com/your-org/beardog
cd beardog

# Build and test
cargo build --release
cargo test

# Run an example
cargo run --example basic_setup
```

### **First Steps**
1. Read [`START_HERE.md`](START_HERE.md) for navigation
2. Review [`ARCHITECTURE.md`](ARCHITECTURE.md) for design overview
