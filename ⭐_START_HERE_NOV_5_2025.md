## 🚦 Getting Started

### 1. Quick Start (5 minutes)
```bash
# Clone and build
git clone <repo-url>
cd beardog
cargo build --release

# Run tests
cargo test

# Start with default config
cargo run
```

### 2. Configuration
```bash
# Copy template
cp configs/beardog-config-template.toml configs/beardog-config.toml

# Edit for your environment
vim configs/beardog-config.toml
```

### 3. Run Tests
```bash
# All tests
cargo test

# Specific module
cargo test --package beardog-tunnel

# With coverage
cargo llvm-cov
```
