## 🔍 Documentation Standards

### Root Level Guidelines

**What Belongs at Root:**
- Core project documentation (README, ARCHITECTURE, etc.)
- Essential guides (START_HERE, deployment)
- Current release notes
- Development standards
- Project status

**What Doesn't:**
- Historical reports → `archive/`
- Audit reports → `docs/audit-reports-*/`
- Release artifacts → `docs/release-docs-*/`
- Session notes → `docs/` or `archive/`

### Naming Conventions

**Established Patterns:**
- `START_HERE*.md` - Entry point guides
- `*_GUIDE*.md` - Comprehensive guides
