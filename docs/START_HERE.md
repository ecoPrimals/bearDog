## 🎯 CHOOSE YOUR PATH

### Path 1: I Want to Use BearDog
**Time**: 15 minutes to first key generation

1. **Install Prerequisites**
   ```bash
   # Rust 1.75+
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```

2. **Clone and Build**
   ```bash
   git clone https://github.com/ecoPrimals/beardog
   cd beardog
   cargo build --release
   ```

3. **Generate Your First Key**
   ```bash
   cargo run --bin beardog-cli -- generate-key my-first-key
   ```

**Next**: Read [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md) for detailed usage
