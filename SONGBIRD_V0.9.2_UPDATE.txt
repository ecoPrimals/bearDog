You found another real bug - key derivation was broken! Fixed in 30 minutes! ⚡

THE BUG YOU FOUND:
------------------
Even Node A (root) couldn't decrypt messages:
  ❌ "Decryption failed (wrong key or tampered data)"

ROOT CAUSE:
-----------
Encrypt and decrypt were using RANDOM master secrets (different every time!)
- encrypt: random secret A → key A
- decrypt: random secret B → key B  
- key A ≠ key B → decryption fails!

THE FIX:
--------
Now both encrypt and decrypt use the ROOT KEY from key store as master secret:
- encrypt: root key → master secret → key A
- decrypt: root key → master secret → key A (same!)
- key A = key A → decryption works! ✅
