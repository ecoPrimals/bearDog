## 🎯 Documentation Philosophy

### Permanent Root Documents
**Purpose**: Long-term reference, frequently accessed

**Examples**:
- Architecture guides
- Quick start guides
- Reference documentation
- Security policies

**Location**: Root directory

---

### Session Documents
**Purpose**: Historical record, specific evolution sessions

**Examples**:
- Session reports
- Evolution plans
- Implementation details
- Metrics and results

**Location**: `docs/sessions/<date>/`

---

### Benefits of This Structure

1. **Clarity**: Easy to distinguish permanent vs historical docs
2. **Accessibility**: Quick access to frequently used guides
3. **History**: Complete record of evolution sessions
4. **Maintainability**: Clean root directory
5. **Scalability**: Easy to add future sessions
