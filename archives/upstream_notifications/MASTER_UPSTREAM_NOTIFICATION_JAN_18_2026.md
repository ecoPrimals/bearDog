### **5. Crypto API for Songbird TLS** ✅ **NEW!**

**8 Pure Rust crypto operations via JSON-RPC:**

| Operation | Method | Use Case |
|-----------|--------|----------|
| **Ed25519 Sign** | `crypto.sign_ed25519` | TLS certificates |
| **Ed25519 Verify** | `crypto.verify_ed25519` | Certificate validation |
| **X25519 Keygen** | `crypto.x25519_generate_ephemeral` | TLS handshake |
| **X25519 DH** | `crypto.x25519_derive_secret` | Shared secret |
| **ChaCha20 Encrypt** | `crypto.chacha20_poly1305_encrypt` | TLS records |
| **ChaCha20 Decrypt** | `crypto.chacha20_poly1305_decrypt` | TLS records |
| **Blake3 Hash** | `crypto.blake3_hash` | Fingerprints |
| **HMAC-SHA256** | `crypto.hmac_sha256` | TLS PRF |

**Result**: Enables Songbird Pure Rust TLS (~5-6 weeks)!
