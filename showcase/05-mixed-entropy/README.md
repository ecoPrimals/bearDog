# Mixed entropy showcase

**Location**: `showcase/05-mixed-entropy/` (crate `beardog-mixed-entropy-showcase`)

## What it is

A minimal runnable crate that will demonstrate BearDog’s **mixed human + device entropy** story. It is wired as a normal Cargo binary so you can `cargo run` from this directory without building the full workspace.

## Run

```bash
cd showcase/05-mixed-entropy
cargo run
```

Current output is a short placeholder; implementation will grow alongside the entropy hierarchy APIs.
