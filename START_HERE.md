## 🏃 Quick Start

### Option 1: Run Tests (Verify Everything Works)
```bash
# All tests
cargo test --workspace

# With coverage
cargo llvm-cov --workspace --html
# Open: target/llvm-cov/html/index.html
```

### Option 2: Start BearDog Server
```bash
# Standalone server (Tower deployment)
BEARDOG_FAMILY_SEED_FILE="./.family.seed" \
BEARDOG_FAMILY_ID="nat0" \
BEARDOG_NODE_ID="node-alpha" \
RUST_LOG=info \
cargo run --bin beardog-server
```

### Option 3: Use as Library
```rust
use beardog::BearDogService;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let service = BearDogService::new().await?;
    // Now using 100% Pure Rust crypto by default!
    Ok(())
}
```
