## 🚀 **Quick Start**

### **1. New Users**
```bash
# Clone the repository
git clone https://github.com/your-org/beardog
cd beardog

# Install dependencies (Rust 1.70+)
rustup update

# Build and test
cargo build --release
cargo test

# Run examples
cargo run --example basic_setup
```
